Titre : Smart POS - Solution de gestion de stock et caisse (Téléphonie & IMEI)
Stack technique : PHP, MySQL, Apache, Bootstrap
Fonctionnalités : Traçabilité unitaire par IMEI/SN, gestion des ventes, tableau de bord, contrôle d'accès par rôles.
Installation : Importer db_smart_pos_php.sql et configurer le fichier de base de données.
